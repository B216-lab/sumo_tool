# SUMO Model Preparation

**SUMO Model Preparation** — локальное приложение с русскоязычным интерфейсом для подготовки транспортных моделей в [SUMO](https://sumo.dlr.de/). Позволяет создать дорожную сеть из OpenStreetMap (OSM) или импортировать готовый сценарий OSM Web Wizard, настроить транспортные зоны (TAZ) и матрицу корреспонденций (OD), после чего сформировать отдельные поездки и маршруты автомобилей.

## Требования

- Windows 10/11.
- Python 3.11 или новее.
- Установленный [Eclipse SUMO](https://sumo.dlr.de/docs/Downloads.php) с инструментами `netconvert`, `od2trips`, `duarouter`, `netedit` и `sumo-gui`.
- Интернет при первом запуске для установки Python-зависимостей.

## Запуск

1. Распакуйте архив программы в отдельную папку.
2. Запустите **`run_demo.bat`**. При первом запуске автоматически создаётся виртуальное окружение и устанавливается PySide6.
3. В первом окне выберите способ работы: **Обычный OSM** или **OSM Web Wizard**.
4. Укажите новую либо существующую **папку проекта** и нажмите **«ОТКРЫТЬ РАБОЧЕЕ ОКНО»**.
5. Если программа не находит SUMO автоматически, укажите расположение папки `SUMO/bin` в рабочем окне.

## Подготовка модели

**Вариант А — обычный OSM:** нажмите **«Выбрать OSM…»**, укажите файл `.osm` и выберите **«СОЗДАТЬ СЕТЬ (netconvert)»**.

**Вариант Б — OSM Web Wizard:** нажмите **«Запустить OSM Web Wizard»**, создайте сценарий и импортируйте полученную папку или ZIP через соответствующую кнопку. Исходный сценарий можно открыть отдельно кнопкой **«Открыть ОРИГИНАЛЬНЫЙ сценарий Wizard»** — без создания собственной матрицы.

После подготовки дорожной сети:

1. Проверьте автоматически созданные зоны TAZ. При необходимости пересоздайте их кнопкой **«СОЗДАТЬ TAZ АВТОМАТИЧЕСКИ»** или исправьте в **NetEdit**. Проверьте направления въездов (`tazSource`) и выездов (`tazSink`).
2. Нажмите **«ОТКРЫТЬ / СОЗДАТЬ OD-МАТРИЦУ»**. Укажите количество поездок между зонами и нажмите **«Сохранить в проект»**. В режиме Wizard матрицу можно предварительно заполнить кнопкой **«Заполнить OD по поездкам Wizard»**.
3. Нажмите **«ПОДГОТОВИТЬ МОДЕЛЬ»**. Программа использует `od2trips` и `duarouter` для создания отдельных поездок и маршрутов автомобилей.
4. Проверьте сообщения в журнале и нажмите **«ЗАПУСТИТЬ SUMO»**.

После изменения TAZ или матрицы **повторно подготовьте модель**, чтобы обновить поездки и маршруты.

## Файлы проекта

Программа сохраняет файлы в выбранной папке проекта:

| Файл | Назначение |
|---|---|
| `project.json` | Настройки проекта |
| `sumo.add.xml` | Транспортные зоны TAZ, источники и стоки |
| `matrix_taz.xml` | Матрица корреспонденций |
| `trips.trips.xml` | Сформированные поездки |
| `routes.rou.xml` | Маршруты автомобилей |
| `sumo.sumocfg` | Конфигурация собственной модели SUMO |

Для обычного OSM также используется `network.net.xml`; для Wizard исходные файлы размещаются в подпапке `wizard/`. Не используйте одну папку проекта для разных дорожных сетей.

## Важно

- Автоматические TAZ — **предварительная разметка**, которую следует проверить перед моделированием. Алгоритм не гарантирует корректного определения всех въездов и выездов на произвольной сети.
- Матрица, полученная из OSM Web Wizard, основана на **синтетическом**, а не измеренном транспортном спросе.
- Для корректной модели необходимы подходящие дорожная сеть, транспортные зоны и данные о поездках. При ошибках проверьте журнал выполнения и настройки TAZ.
